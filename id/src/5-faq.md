# FAQ lernOS

Di halaman ini kami mengumpulkan **jawaban atas pertanyaan yang sering diajukan**. Jika pertanyaan Anda tidak tercantum, Anda dapat menuliskannya di kolom komentar di bawah.



**Saya ingin mulai dengan lernOS, tetapi tidak tahu persis caranya. Apa saja tipsnya?**

Tempat yang baik untuk memulai adalah [Community CONNECT](https://community.cogneon.de) dengan lebih dari 1.600 anggota dan Community Call bulanan. Untuk mengetahui tanggal-tanggalnya, Anda dapat mendaftar di [grup kami di Meetup](https://www.meetup.com/lernos-connect/). Anda juga dapat bertanya di media sosial seperti Twitter atau LinkedIn (tagar: #lernos). Jika Anda ingin memulai tandem belajar atau kelompok belajar, kami merekomendasikan [Peerfinder](https://web.peerfinder.app/).

**Di mana saya dapat menemukan file PDF, Word, dan e-book untuk panduan?**

Dalam versi web panduan, klik *Downloads* di sidebar sebelah kiri. Jika tidak tertaut di sana, Anda dapat mencoba tautan langsung ke repositori GitHub di atas. Di sana Anda akan menemukan file-file tersebut di folder versi bahasa yang bersangkutan (misalnya de, en).

**Dapatkah saya membaca panduan lernOS di e-book reader seperti Kindle?**

Ya, panduan tersedia dalam format e-book [EPUB](https://id.wikipedia.org/wiki/EPUB) dan [Mobipocket](https://de.wikipedia.org/wiki/Mobipocket). Untuk Kindle misalnya, Anda harus mengirim file mobi ke alamat email Kindle (ditampilkan di pengaturan). Dengan perangkat lunak manajemen e-book seperti [Calibre](https://calibre-ebook.com/), file epub dapat ditambahkan dengan cara drag & drop.

**Dapatkah saya menggunakan dan memodifikasi konten lernOS?**

Ya, Anda bisa dan kami bahkan menginginkannya! Untuk alasan ini, konten lernOS diterbitkan di bawah lisensi [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/deed.id) (CC BY). Anda dapat mengunduh, menggunakan, dan memodifikasi konten tersebut. Anda dapat menggunakan konten lernOS dalam konteks pribadi maupun komersial secara gratis.

**Apa perbedaan antara lernOS dan metode lain seperti Working Out Loud (WOL)?**

Lihat [Blog tentang perbedaan terpenting](https://cogneon.de/2019/07/13/di3-13-wichtigsten-unterschiede-zwischen-lernos-und-wol/).

**Dapatkah saya menawarkan produk dan layanan komersial dengan nama lernOS di dalamnya?**

Tidak. Produk dan layanan individual tidak boleh menyertakan istilah 'lernOS' dalam namanya (misalnya 'lernOS Lernwerkstatt'). Ini seperti browser web open source [Chromium](https://www.chromium.org/Home), yang kode sumbernya dapat digunakan oleh siapa saja. Namun, produk yang didasarkan pada ini harus memiliki nama yang berbeda ([Google Chrome](https://id.wikipedia.org/wiki/Google_Chrome), [Microsoft Edge](https://id.wikipedia.org/wiki/Microsoft_Edge), [Opera](https://id.wikipedia.org/wiki/Opera_(browser)), [Flock](https://id.wikipedia.org/wiki/Flock_(web_browser)), [Brave](https://id.wikipedia.org/wiki/Brave_(web_browser))).

**Saya ingin membuat panduan lernOS sendiri, bagaimana caranya?**
Pembuatan panduan lernOS dijelaskan dalam [Panduan Templat lernOS](https://cogneon.github.io/lernos-template/de/). Jika Anda ingin menulis panduan, langkah pertama yang terbaik adalah menghubungi [Simon Dückert](https://www.linkedin.com/in/simondueckert/).
